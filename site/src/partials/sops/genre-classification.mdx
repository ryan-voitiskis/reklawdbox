## Constraints

- **Taxonomy is compiled.** The alias map in `genre.rs` cannot be changed at runtime. If the user disagrees with a mapping, the agent works around it by using the user's preferred genre directly.
- **No auto-tagging.** Every genre change requires explicit human approval.
- **Cache-first.** Classification runs from cached data. If cache is empty for a track, it is flagged as insufficient evidence — do not trigger enrichment mid-classification.
- **XML export only.** No direct DB writes. All changes flow through `update_tracks` → `preview_changes` → `write_xml`.
- **Per-track reasoning is mandatory for low/insufficient confidence.** Do not skip or batch-approve these tracks. Delegate to subagents if the volume is large.

## Prerequisites

```
cache_coverage(has_genre=false)
```

All providers must be at 100% before proceeding. If not, hydrate first:

```
analyze_audio_batch(has_genre=false, skip_cached=true, max_tracks=200)
enrich_tracks(has_genre=false, skip_cached=true, providers=["discogs"], max_tracks=50)
enrich_tracks(has_genre=false, skip_cached=true, providers=["beatport"], max_tracks=50)
```

Repeat until all providers reach 100%. Report progress between batches.

## Steps

### 1. Normalize aliases

```
suggest_normalizations()
```

Stage non-debatable fixes (e.g. `Hip-Hop` → `Hip Hop`, `DnB` → `Drum & Bass`):

```
update_tracks(changes=[{"track_id": "...", "genre": "..."}])
```

For debatable aliases, ask the user. Store overrides for Step 2.

**Unknown genres** (non-canonical, no alias mapping) must be classified through the same pipeline as ungenred tracks. Collect their track IDs for Step 2.

### 2. Classify all tracks

Classify the full scope before reviewing anything. This gives an accurate confidence distribution and enables efficient review.

```
classify_tracks(max_tracks=50, format="compact", genre_overrides=[...])
```

Paginate with `offset` until all ungenred tracks are processed. Then classify the unknown-genre tracks from Step 1:

```
classify_tracks(track_ids=[...unknown IDs...], format="compact", genre_overrides=[...])
```

Collect all results into a roster. Report the aggregate distribution:

```
"N tracks classified: X high, Y medium, Z low, W insufficient."
```

### 3. Set approval policy

Present the confidence distribution and ask the user which tiers to auto-approve:

**"Approve all high-confidence? Approve high and medium? Or review everything?"**

Default recommendation: approve high, present medium as summary, full review for low/insufficient.

### 4. Stage auto-approved tiers

#### High confidence

Present a genre-grouped summary before staging:

```
High confidence (N tracks):
  Techno: 58 — G-Man (30), Aril Brikha (14), Marcel Dettmann (8), ...
  Breakbeat: 12 — Octo Octa (4), Gacha Bakradze (4), ...
  House: 7 — Tim Deluxe (2), Enliven (2), ...
```

Stage after user confirms.

#### Medium confidence

If the user auto-approved medium, present the same genre-grouped summary and stage.

If not auto-approved, present as a numbered list grouped by genre. Highlight which evidence sources agree vs disagree:

```
→ Techno (8):
 #1  Cristi Cons — Bird In Space (Discogs: Techno, label: Cocoon → Techno, 124bpm)
 #2  Polar Inertia — Black Sun remix (Discogs: Techno, 131bpm)
 ...
```

Ask: **"Approve all, or reject/change specific numbers. Say 'investigate #N' for any you want more context on."**

For investigated tracks, use `resolve_tracks_data` to get full evidence, then check artist context via `search_tracks`.

Stage approved changes.

### 5. Review low and insufficient confidence

These tracks need per-track reasoning — do not batch-approve them. Use subagents to parallelize the work.

#### 5.1 Group by artist

From the compact roster, group low/insufficient tracks by artist:

- Artists with 5+ tracks → dedicated subagent
- Remaining artists → batch into subagents of ~15–20 tracks

#### 5.2 Dispatch review subagents

Launch subagents in parallel (3–4 at a time). Each subagent receives:

- A list of tracks: `(track_id, artist, title, suggested_genre, confidence)`
- The review prompt below

**Review subagent prompt:**

> You are classifying genres for tracks in a Rekordbox library. For each track, produce a genre recommendation with reasoning.
>
> **Tools available:**
> - `resolve_tracks_data(track_ids=[...], format="classification")` — full classification evidence
> - `search_tracks(artist="...", has_genre=true)` — artist's other genred tracks in the library
> - `get_track(track_id="...")` — single track detail
>
> **For each track:**
> 1. Call `resolve_tracks_data` to get full evidence (Discogs, Beatport, label, audio)
> 2. Check if the artist has other genred tracks in the library — what genres are they?
> 3. Consider artist reputation, label identity, and track title
> 4. Recommend a canonical genre with one-sentence reasoning
>
> **Output format:**
> ```
> #N  Artist — Title
>     Evidence: [summary of sources]
>     Library: [artist's other genres, or "no other tracks"]
>     Recommend: GENRE — [why]
> ```
>
> **Tracks to classify:**
> [track list here]

#### 5.3 Present recommendations

As each subagent completes, present its recommendations to the user in the `#N Artist — Title / Evidence / Library / Recommend` format.

Ask: **"Approve all, or reject/change specific numbers."**

Stage approved changes. Repeat until all subagents have reported.

Report cumulative progress: `"Review complete: N classified, M changes staged, K remaining."`

### 6. Export

```
preview_changes()
```

Ask user: "Export these changes to XML?"

```
write_xml()
```

Report output path, then walk the user through the Rekordbox import:

1. **Add XML to Rekordbox** — Open Preferences → Advanced → rekordbox xml → **Imported Library** → Browse → select the exported XML file.
2. **Open the XML view** — In the sidebar, click the **"Display rekordbox xml"** icon. The imported tracks appear under "All Tracks".
3. **Import into collection** — Select all tracks (Cmd+A), right-click → **Import To Collection**. When prompted "Do you want to load information in the tag of the library being imported?", click **Yes** (tick "Don't ask me again" for bulk imports).
