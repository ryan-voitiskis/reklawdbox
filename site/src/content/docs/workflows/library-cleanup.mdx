Five sessions that build on each other. Follow them in order — each one depends on the last.

Before you start, consider running a [Library Health](/workflows/library-health/) scan to catch broken links, orphan files, and duplicates. Fixing structural issues first saves you from redoing work later.

<Aside type="caution">
  Session 1 writes directly to your audio files. Sessions 3-5 stage changes as XML — your Rekordbox database only updates after you import the XML yourself. Complete each checkpoint before moving on. Session 2 is a terminal command, not an agent session.
</Aside>

## Why order matters

**Clean metadata > accurate enrichment > label data > genre signals**

Enrichment matches on artist and title — typos cause missed matches. Genre classification uses enrichment and audio analysis as evidence. If you skip ahead, you'll get worse results and end up re-running things.

## Sessions

### Session 1: Collection Audit

<Badge text="Requires" variant="note" /> reklawdbox connected

Paste into your agent:

```
Audit my collection for naming and tagging issues.
```

This fixes artist names, track titles, and file naming conventions. Getting these right first means better enrichment match rates in Session 2.

<LinkCard title="Collection Audit details" href="/workflows/collection-audit/" />

#### Checkpoint

No XML needed here — Collection Audit writes directly to files. If the agent
lists successfully changed imported tracks, select **only** those tracks in
Rekordbox and choose **Reload Tag**. This is a hard checkpoint: wait for the
agent to verify a bounded sample of artist/title/album values before starting
Session 2.

Reload Tag can overwrite intentional Rekordbox database-only edits with values
from the audio files. For WAV files, label and track number are not available in
RIFF INFO and will not update through Reload Tag.

---

### Session 2: Enrichment

<Badge text="Requires" variant="note" /> Session 1 complete

Run this in your terminal (not through the agent):

```sh
reklawdbox hydrate --cpu overnight -y
```

This fetches metadata from Discogs, Beatport, MusicBrainz, and Bandcamp, plus runs audio analysis on every track. `--cpu overnight` uses most of your cores; `-y` skips the confirmation prompt.

When it finishes, run `reklawdbox hydrate` again — it'll report any remaining gaps. All providers should be at 100% before moving on.

---

### Session 3: Metadata Backfill

<Badge text="Requires" variant="note" /> Session 2 complete (all providers at 100%)

Paste into your agent:

```
Find tracks missing labels and years in my collection and fill them from enrichment data.
```

Labels are the strongest genre signal for electronic music. Years give era context. The agent fills in what's missing from enrichment data and shows you any conflicts for review.

<LinkCard title="Metadata Backfill details" href="/workflows/metadata-backfill/" />

#### Checkpoint

The agent will ask to export to XML. Approve, then import into Rekordbox:

<XmlImportSteps />

Start a fresh session for Session 4.

---

### Session 4: Genre Classification

<Badge text="Requires" variant="note" /> Session 3 XML imported

Paste into your agent:

```
Classify genres for my ungenred tracks.
```

The agent normalizes any genre aliases first, then classifies tracks in batches. You review results grouped by confidence — high and medium confidence can usually be approved in bulk, while low confidence needs a closer look.

<LinkCard title="Genre Classification details" href="/workflows/genre-classification/" />

#### Checkpoint

Export to XML, import into Rekordbox. Verify a few genres look right, then start a fresh session for Session 5.

<XmlImportSteps />

---

### Session 5: Genre Audit

<Badge text="Requires" variant="note" /> Session 4 XML imported

Paste into your agent:

```
Audit my existing genre tags.
```

This checks your existing genre tags against enrichment and audio evidence. It only shows you conflicts and things that need a second look — confirmed genres are skipped.

<LinkCard title="Genre Audit details" href="/workflows/genre-audit/" />

#### Checkpoint

Export to XML, import into Rekordbox. Spot-check the corrections.

<XmlImportSteps />

## Skipping sessions

- **Metadata already clean?** Start at Session 2.
- **Already enriched?** Re-run `reklawdbox hydrate` — if all providers are at 100%, jump to Session 3.
- **Labels and years present?** Skip Session 3.
- **No ungenred tracks?** Skip Session 4.
- **No existing genre tags?** Skip Session 5.
