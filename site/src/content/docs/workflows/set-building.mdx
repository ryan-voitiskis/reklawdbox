Builds ordered tracklists scored across six axes: key compatibility, BPM, energy, genre, brightness, and rhythm. The agent explores multiple paths and presents candidates for you to compare.

Paste into your agent:

```
Build a DJ set from my collection.
```

## Prerequisites

- The only hard requirements are a resolvable candidate pool and valid tool
  parameters.
- Rekordbox BPM, key, and genre make their scoring axes more useful.
- Missing BPM, key, or genre degrades the corresponding scoring axis; it does not block the workflow.
- Built-in Stratum can supply BPM or key evidence when Rekordbox values are
  absent; scoring also uses the Rekordbox values when available.
- Essentia is recommended for richer energy, brightness, and rhythm scoring;
  related pool tools also use its timbral features. Optional axes degrade
  gracefully when it is unavailable.

## Energy curves

The agent shapes the energy arc across your set. Four presets are available:

- **warmup_build_peak_release** (default) — the classic DJ arc
- **flat** — every track at peak energy, for peak-time sets
- **peak_only** — fast ramp to peak, good for shorter sets or festival slots
- **custom** — define the energy phase for each position yourself

See [Harmonic Mixing](/concepts/harmonic-mixing/) for the full scoring model.

## Tips

- **Start with a larger pool than you need.** A 12-track set benefits from 40-60 candidates.
- **Pin your opener and closer first.** The agent optimizes the middle.
- **Use genre focus loosely.** "Techno, Tech House" gives better results than "Techno" alone.
- **Re-run with different priority axes.** A "harmonic" build and an "energy" build can look very different.
- **Check individual transitions.** Ask the agent to score any two tracks to see the axis-by-axis breakdown.
