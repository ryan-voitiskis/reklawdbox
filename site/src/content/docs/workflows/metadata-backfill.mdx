Fill missing labels, years, and albums from Discogs, Beatport, Bandcamp, MusicBrainz, file tags, and folder paths. Labels are the strongest genre signal for electronic music; years provide era context for classification and set building. Albums round out the metadata for library browsing.

**Paste into your agent to start:**

```
Find tracks missing labels and years in my collection and fill them from enrichment data.
```

<Aside type="caution">
  Label conflicts require your approval. Year conflicts are resolved automatically using the earliest year. Album backfill only fills empty values — no conflicts.
</Aside>

## When to backfill

- After enrichment hydration completes (100% cache coverage)
- Before genre classification — labels and years improve classification accuracy
- After importing tracks from another collection that may lack label/year metadata
- Periodically, as new enrichment data becomes available (e.g. Beatport label extraction)

## How it works

Three backfill tools run in sequence:

1. **`backfill_labels`** — pulls labels from all four enrichment providers. Empty labels are auto-staged; conflicts are grouped by pattern for review. Remaining gaps are researched by the agent.
2. **`backfill_years`** — tries six sources in priority order (file tags, folder path, Discogs, Beatport, MusicBrainz, Bandcamp). Conflicts auto-resolve to the earliest year. Remaining gaps are researched by the agent.
3. **`backfill_albums`** — fills empty albums from file tags, folder paths, Bandcamp, and Discogs. Best-effort only — empty album is valid for singles and loose tracks.

## Cache coverage

All providers should be at 100% before starting. Run `cache_coverage(has_label=false)` to check. If any provider is below 100%, hydrate first.

<Aside type="tip">
  Use `auto_enrich=true` on backfill tools to automatically fetch missing Bandcamp data inline — slower but requires no manual batching.
</Aside>
