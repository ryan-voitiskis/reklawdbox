Fills missing labels, years, and albums using data from Discogs, Beatport, Bandcamp, MusicBrainz, file tags, and folder paths. Labels are the strongest genre signal for electronic music, and years give era context that improves classification.

Paste into your agent:

```
Find tracks missing labels and years in my collection and fill them from enrichment data.
```

## How it works

The agent runs three backfill passes:

1. **Labels** — pulls from all four enrichment providers. Empty labels are filled automatically; conflicts are grouped for your review.
2. **Years** — checks six sources in priority order (file tags, folder path, Discogs, Beatport, MusicBrainz, Bandcamp). Conflicts auto-resolve to the earliest year.
3. **Albums** — fills empty albums from file tags, folder paths, Bandcamp, and Discogs. Best-effort — an empty album is fine for singles and loose tracks.

Label conflicts always need your approval. Year conflicts resolve automatically. Albums only fill empty values, so there are no conflicts.

## Prerequisites

Start with scoped `cache_coverage` as a Discogs, Beatport, and audio-analysis
baseline. A searched no-match is valid completion; unavailable releases do not
need to produce a match. The workflow uses targeted Bandcamp enrichment,
individual MusicBrainz lookups, `auto_enrich`, and web research for the gaps
those baseline sources leave behind.
