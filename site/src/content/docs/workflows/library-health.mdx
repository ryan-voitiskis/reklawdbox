No enrichment or cache coverage needed — all scanning is built-in.

## When to scan

- Before starting [Library Cleanup](/workflows/library-cleanup/) — catch structural issues first
- After moving or reorganizing files on disk
- After a large batch import
- Periodically, as general maintenance

## What it checks

1. **Broken links** — tracks in Rekordbox pointing to files that no longer exist. Suggests relocations when a match is found elsewhere.
2. **Orphan files** — audio files on disk that aren't imported into Rekordbox.
3. **Playlist coverage** — tracks not assigned to any playlist.
4. **Duplicates** — matching artist + title, or exact file hash matches.
