Plan a full night from locked **chapters** (validated pools) connected by **bridge tracks**. Each chapter is an improvisation-ready crate; bridges handle the transitions between them.

**Paste into your agent to start:**

```
Plan a set from my locked chapters.
```

<Aside type="note">
  This workflow assumes you've already built and locked chapters using the [Pool Building](/workflows/pool-building/) workflow.
</Aside>

## Terminology

- **Chapter** — a locked pool the DJ has validated. Either **sequenced** (fixed order) or **unordered** (improvise order live).
- **Bridge** — 1-3 tracks connecting two chapters, compatible with both the tail of one and the head of the next.
- **Set plan** — the full structure: chapter order, bridges, overall energy arc.

## When to use this vs Set Building

| Goal | Workflow |
|------|----------|
| Single pool, fixed sequence | [Set Building](/workflows/set-building/) |
| Multiple pools, improvise within each | **Chapter Set Planning** |
| Just finding compatible tracks | [Pool Building](/workflows/pool-building/) |
