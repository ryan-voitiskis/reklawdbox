Plan a full night from **chapters** (pools you've already built and validated) connected by **bridge tracks**. Each chapter is an improvisation-ready crate; bridges handle the transitions between them.

Paste into your agent:

```
Plan a set from my locked chapters.
```

This assumes you've already built chapters using [Pool Building](/workflows/pool-building/).

## Prerequisites

- At least two locked chapter playlists and a clear sequenced/unordered choice
  for each chapter are hard requirements.
- Bridge and sequence tools still need valid candidates and parameters.
- Missing BPM, key, or genre degrades the corresponding scoring axis; it does not block the workflow.
- Built-in Stratum supplies BPM and key evidence when available. Essentia is
  recommended for energy, brightness, rhythm, and timbral evidence, but missing
  optional axes degrade gracefully.

## Key terms

- **Chapter** — a locked pool you've validated. Can be sequenced (fixed order) or unordered (improvise live).
- **Bridge** — 1-3 tracks connecting two chapters, compatible with the tail of one and the head of the next.
- **Set plan** — the full structure: chapter order, bridges, overall energy arc.

## When to use this vs Set Building

- **Single pool, fixed sequence** — use [Set Building](/workflows/set-building/)
- **Multiple pools, improvise within each** — use Chapter Set Planning
- **Just finding compatible tracks** — use [Pool Building](/workflows/pool-building/)
