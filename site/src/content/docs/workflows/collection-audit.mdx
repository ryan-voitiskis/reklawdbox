Fixes artist names, track titles, file naming, and tagging issues so everything is clean before enrichment. Genre tagging is a separate step — see [Genre Classification](/workflows/genre-classification/).

Paste into your agent:

```
Audit my collection for naming and tagging issues.
```

To scope to a specific directory:

```
Audit /path/to/music for naming and tagging issues.
```

## WAV tagging

Rekordbox only reads RIFF INFO tags from WAV files, ignoring ID3v2 entirely. If your WAVs only have ID3v2 tags (common with files from Bandcamp, Beatport, etc.), Rekordbox shows them as untagged.

The audit catches these issues and the agent writes both tag formats automatically.

## Imported file protection

Files already imported into Rekordbox are never renamed — Rekordbox stores absolute paths and can't update them through XML. To rename an imported file: delete it from Rekordbox first, rename, then re-import.

## After fixes

For every successful tag change to an imported track, the agent lists the exact
tracks for you to select in Rekordbox and **Reload Tag** before enrichment. The
workflow pauses for your confirmation, then verifies a small sample against the
file tags. Reload Tag can overwrite intentional Rekordbox-only edits with the
values stored in the audio file, so select only the listed tracks.

WAV Reload Tag reads RIFF INFO, which does not support label or track-number
fields. Those fields still need XML import or a manual Rekordbox edit when they
change.

## File naming conventions

**Album tracks:** `NN Artist Name - Track Title.ext`
e.g. `01 Actress - Maze.flac`, `12 Four Tet - Baby.wav`

**Loose tracks:** `Artist Name - Track Title.ext`
e.g. `Burial - Archangel.flac`, `Joy Orbison - Hyph Mngo.wav`

**Album directories:** `Album Name (Year)/`
e.g. `Untrue (2007)/`, `New Energy (2017)/`
