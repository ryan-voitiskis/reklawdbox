Every workflow follows the same pattern: scope tracks, gather evidence, present recommendations by confidence, get human approval, stage and export. The agent does the tedious work; you make the final call.

All workflows require cached data. Run `cache_coverage` first — if any provider is below 100%, hydrate with `analyze_audio_batch` and `enrich_tracks` before starting.

## Where to start

- **Tags and filenames are messy?** [Collection Audit](/workflows/collection-audit/)
- **Metadata is clean, need genres?** [Genre Classification](/workflows/genre-classification/)
- **Want to verify existing genres?** [Genre Audit](/workflows/genre-audit/)
- **Want to build a set?** [Set Building](/workflows/set-building/)
- **Prepping pools for a gig?** [Pool Building](/workflows/pool-building/)
- **Planning a full night?** [Chapter Set Planning](/workflows/chapter-set-planning/)
- **Just acquired new music?** [Batch Import](/workflows/batch-import/)
- **Prepping for a gig or exploring your library?** [DJ Prompts](/workflows/dj-prompts/)

<Aside type="tip" title="Messy library?">
  Workflows build on each other — clean metadata improves enrichment, enrichment improves classification. Follow the [Library Cleanup](/workflows/library-cleanup/) guide for the recommended session sequence.
</Aside>
