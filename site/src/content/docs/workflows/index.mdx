## What are you trying to do?

Choose the task that matches what you want to do. Each option says when to use
it, how much time to allow, and whether it can change files or prepare changes
for Rekordbox.

If you only wanted to confirm that ChatGPT or Claude Desktop can connect, the
[first session](/getting-started/first-session/) is enough. Choose a workflow
when you have a specific task. If that task is checking files, duplicates, or
playlist gaps, [Library Health](/workflows/library-health/) is the read-only
choice.
