## What are you trying to do?

Choose by the result you want and the effects you are comfortable with. Workflows
do not share one lifecycle: some only scan, some write tags or organize files,
some stage metadata for review, and some create XML for a separate Rekordbox
handoff.

Each card shows collection impact, network use, local state, files created,
prerequisites, scope, and the final Rekordbox step before you commit to a path.
Conditional and optional effects are labelled explicitly.

**Not sure where to begin?** Start with [Library Health](/workflows/library-health/).
It is network-free and collection-read-only. Its runtime still depends on library
size, and any suggested fixes are separate manual actions.

Before choosing a workflow that writes files or exports XML, read
[Safety & Trust](/concepts/safety/). For provider and cache readiness, see
[Enrichment & Analysis](/mcp-tools/enrichment-analysis/).
