Builds unordered pools of tracks that mix well together in any direction. Unlike [Set Building](/workflows/set-building/) (which produces a fixed sequence), pools are crates for live improvisation — any permutation works.

Paste into your agent:

```
Build a track pool from my collection.
```

Pool analysis is read-only. Export is a separate step that writes an XML
playlist; it does not write the Rekordbox database.

## Prerequisites

- The only hard requirements are valid seed or candidate tracks and valid tool
  parameters.
- Rekordbox BPM, key, and genre improve compatibility scoring.
- Missing BPM, key, or genre degrades the corresponding scoring axis; it does not block the workflow.
- Built-in Stratum supplies BPM and key evidence when available, with Rekordbox
  metadata as the complementary source.
- Essentia is recommended for energy, brightness, rhythm, and timbral scoring,
  but unavailable axes degrade gracefully.

## How it differs from set building

Pool scoring is **symmetric** — score(A,B) always equals score(B,A). There are no energy phases, no genre streaks, no BPM drift penalties. The question is "do these tracks belong in the same crate?" not "should B follow A?"

## Presets

- **balanced** (default) — BPM and energy lead, with timbral similarity as the discovery axis
- **timbral** — upweights timbral similarity for cross-genre sonic discovery

## Master tempo

Pool tools default to `master_tempo=false`, which accounts for the pitch shift that happens when you adjust BPM without master tempo on. If you play with Rekordbox's master tempo enabled, set `master_tempo=true`.

See [Pool Discovery](/concepts/pool-discovery/) for the full scoring model and expansion algorithm.
