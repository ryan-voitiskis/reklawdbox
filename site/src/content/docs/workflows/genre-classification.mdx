Classify genres using cached evidence from Discogs, Beatport, and audio analysis. Recommendations are grouped by confidence level — every change requires your approval.

**Paste into your agent to start:**

```
Classify genres for my ungenred tracks.
```

<Aside type="caution">
  No auto-tagging. Every genre change requires your explicit approval before it is staged or exported.
</Aside>

## Cache coverage

All providers must be at 100% before starting. Run `cache_coverage(has_genre=false)` to check. If any provider is below 100%, hydrate first.

<Aside type="tip">
  Run audio analysis first (local, fast), then enrichment (external, rate-limited). This order minimizes wall-clock time.
</Aside>

## How it works

`classify_tracks` applies the genre decision tree server-side using all cached evidence (Discogs styles, Beatport genre, label mappings, audio analysis). Results are grouped by confidence with a summary.

## Confidence levels

- **High** — full consensus from multiple sources (Discogs + Beatport agree, BPM plausible)
- **Medium** — partial consensus or single-source match
- **Low** — weak or ambiguous evidence (split sources, audio-only inference)
- **Insufficient** — conflicting or missing data, requires manual decision
