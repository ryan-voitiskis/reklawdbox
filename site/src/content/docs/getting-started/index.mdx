## Prerequisites

- **macOS on Apple Silicon** (ARM64) — reklawdbox targets `aarch64-apple-darwin`
- **Rekordbox 7.x** installed with at least one collection imported

## Install

<Tabs>
  <TabItem label="Homebrew (recommended)">
    ```bash
    brew tap ryan-voitiskis/reklawdbox
    brew install reklawdbox
    ```

    The binary is installed to `/opt/homebrew/bin/reklawdbox`.
  </TabItem>
  <TabItem label="Build from source">
    Requires the [Rust toolchain](https://rustup.rs/) and Xcode Command Line Tools:

    ```bash
    xcode-select --install  # if not already installed
    git clone https://github.com/ryan-voitiskis/reklawdbox.git
    cd reklawdbox
    cargo build --release
    ```

    The binary is at `./target/release/reklawdbox`.
  </TabItem>
</Tabs>

## Setup

```bash
reklawdbox setup
```

This command does three things:

1. **Installs Essentia** — finds Python 3.9+, creates a managed venv at `~/.local/share/reklawdbox/essentia-venv`, and installs Essentia via pip. Provides danceability, energy, loudness, and spectral features used by genre classification, set building, and audio analysis.

2. **Configures Claude Code** — writes `~/Music/.mcp.json` so reklawdbox tools are available when you start Claude Code from your Music directory. Tools do not load in other projects.

3. **Configures Claude Desktop** — adds reklawdbox to the Claude Desktop config (loads globally, since Desktop has no project scoping).

<Aside type="tip" title="Why ~/Music?">
  Reklawdbox tools are scoped to `~/Music` to avoid polluting unrelated Claude Code sessions. When you start Claude Code from `~/Music`, the tools load automatically. When you're working in a code project, they stay out of the way. To add reklawdbox to other directories, see [Adding to other directories](#adding-to-other-directories).
</Aside>

<Aside type="note">
  Essentia requires Python 3.9 or later. If you don't have Python installed, get it from [python.org](https://www.python.org/downloads/) or via `brew install python`.
</Aside>

## Using with Claude Code

After running `reklawdbox setup`, start Claude Code from your Music directory:

```bash
cd ~/Music && claude
```

Reklawdbox tools load automatically because setup placed `.mcp.json` there. In any other directory, the tools stay out of the way.

### Adding to other directories

To make reklawdbox available in additional directories, copy `~/Music/.mcp.json` to the target directory:

```bash
cp ~/Music/.mcp.json /path/to/directory/
```

If you built from source, check that the `command` path inside the copied file points to your binary.

Or create a new `.mcp.json` there with the following content:

```json
{
  "mcpServers": {
    "reklawdbox": {
      "command": "/opt/homebrew/bin/reklawdbox"
    }
  }
}
```

If you built from source, use the full absolute path to the binary (e.g., `/Users/you/reklawdbox/target/release/reklawdbox`).

<Aside type="caution">
  If you previously registered reklawdbox at user scope (e.g., via `claude mcp add`), that entry in `~/.claude.json` overrides any project `.mcp.json`. Remove it first: `claude mcp remove -s user reklawdbox`. See [Troubleshooting](/troubleshooting/#tools-appearing-in-every-project).
</Aside>

## Manual MCP host configuration

If `reklawdbox setup` already configured your MCP host, skip to [Verify](#verify). Otherwise, configure manually:

<Tabs>
  <TabItem label="Claude Code">
    Create `~/Music/.mcp.json`:

    ```json
    {
      "mcpServers": {
        "reklawdbox": {
          "command": "/opt/homebrew/bin/reklawdbox"
        }
      }
    }
    ```

    If you built from source, use the full absolute path to the binary instead. Then start Claude Code from `~/Music`:

    ```bash
    cd ~/Music && claude
    ```
  </TabItem>
  <TabItem label="Claude Desktop">
    Add the following to your Claude Desktop config (`~/Library/Application Support/Claude/claude_desktop_config.json`):

    ```json
    {
      "mcpServers": {
        "reklawdbox": {
          "command": "/opt/homebrew/bin/reklawdbox"
        }
      }
    }
    ```

    If you built from source, use the full absolute path to the binary (e.g., `/Users/you/reklawdbox/target/release/reklawdbox`).
  </TabItem>
  <TabItem label="Codex">
    ```bash
    codex mcp add reklawdbox -- /opt/homebrew/bin/reklawdbox
    ```
  </TabItem>
</Tabs>

<Aside type="tip">
  The Rekordbox database is auto-detected at `~/Library/Pioneer/rekordbox/master.db`. Set `REKORDBOX_DB_PATH` only for non-standard locations.
</Aside>

<Aside type="caution">
  After configuring your MCP host, reload it to pick up the changes. In Claude Code, run `/mcp` or start a new conversation. In Claude Desktop, quit and reopen the app.
</Aside>

## Verify

Start a new conversation and paste this:

```text
Show me a summary of my Rekordbox library.
```

It should return your track count, playlist count, and genre distribution. If it fails, check [Troubleshooting](/troubleshooting/).

## Discogs authorization

Discogs enrichment provides labels, catalog numbers, and release metadata used by genre classification and library cleanup. The broker is preconfigured — no env vars or setup needed.

<Steps>

1. Call `lookup_discogs` for any track. On first use, the broker returns an OAuth URL — open it in your browser.

2. After authorizing, subsequent calls work automatically.

</Steps>
