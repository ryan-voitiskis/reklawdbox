## Prerequisites

- **macOS on Apple Silicon** (ARM64) — reklawdbox targets `aarch64-apple-darwin`
- **Rekordbox 7.x** installed with at least one collection imported

## Install

<Tabs>
  <TabItem label="Homebrew (recommended)">
    ```bash
    brew tap ryan-voitiskis/reklawdbox
    brew install reklawdbox
    ```

    The binary is installed to `/opt/homebrew/bin/reklawdbox`.
  </TabItem>
  <TabItem label="Build from source">
    Requires the [Rust toolchain](https://rustup.rs/).

    ```bash
    git clone https://github.com/ryan-voitiskis/reklawdbox.git
    cd reklawdbox
    cargo build --release
    ```

    The binary is at `./target/release/reklawdbox`.
  </TabItem>
</Tabs>

## MCP host configuration

<Tabs>
  <TabItem label="Claude Code">
    Add directly from the CLI:

    ```bash
    claude mcp add reklawdbox \
      -e CRATE_DIG_ESSENTIA_PYTHON="/Users/<you>/.local/share/reklawdbox/essentia-venv/bin/python" \
      -- /opt/homebrew/bin/reklawdbox
    ```

    Or add an `.mcp.json` file in the project root:

    ```json
    {
      "mcpServers": {
        "reklawdbox": {
          "type": "stdio",
          "command": "/opt/homebrew/bin/reklawdbox",
          "env": {
            "CRATE_DIG_ESSENTIA_PYTHON": "/Users/<you>/.local/share/reklawdbox/essentia-venv/bin/python"
          }
        }
      }
    }
    ```

    If you built from source, use `./target/release/reklawdbox` instead.
  </TabItem>
  <TabItem label="Claude Desktop">
    Add the following to your Claude Desktop config (`~/Library/Application Support/Claude/claude_desktop_config.json`):

    ```json
    {
      "mcpServers": {
        "reklawdbox": {
          "type": "stdio",
          "command": "/opt/homebrew/bin/reklawdbox",
          "env": {
            "CRATE_DIG_ESSENTIA_PYTHON": "/Users/<you>/.local/share/reklawdbox/essentia-venv/bin/python"
          }
        }
      }
    }
    ```

    If you built from source, use `./target/release/reklawdbox` instead.
  </TabItem>
  <TabItem label="Codex">
    Codex requires a wrapper script since it doesn't support `env` in its MCP config.

    Create a launcher script (e.g., `scripts/launch-reklawdbox.sh`):

    ```bash
    #!/bin/bash
    export CRATE_DIG_ESSENTIA_PYTHON="/Users/<you>/.local/share/reklawdbox/essentia-venv/bin/python"
    exec /opt/homebrew/bin/reklawdbox
    ```

    Then register it:

    ```bash
    codex mcp add reklawdbox -- bash scripts/launch-reklawdbox.sh
    ```
  </TabItem>
</Tabs>

<Aside type="tip">
  The Rekordbox database is auto-detected at `~/Library/Pioneer/rekordbox/master.db`. Set `REKORDBOX_DB_PATH` only for non-standard locations.
</Aside>

## Verify

Ask your agent to call `read_library`. It should return track count, playlist count, and genre distribution. If it fails, check [Troubleshooting](/troubleshooting/).

## Optional: Essentia setup

Essentia adds advanced audio descriptors (danceability, energy, spectral features).

<Steps>

1. Run `bash scripts/setup-essentia.sh`

2. Set `CRATE_DIG_ESSENTIA_PYTHON` in your MCP config to the venv path printed by the script (typically `~/.local/share/reklawdbox/essentia-venv/bin/python`).

3. Verify by calling `setup_essentia` through your agent.

</Steps>

## Optional: Discogs enrichment

The broker is preconfigured — no extra env vars needed.

<Steps>

1. Call `lookup_discogs` for any track. On first use, the broker returns an OAuth URL — open it in your browser.

2. After authorizing, subsequent calls work automatically.

</Steps>
