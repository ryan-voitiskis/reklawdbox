## Prerequisites

- **macOS on Apple Silicon** — M1 or later
- **Rekordbox 7.x** installed with at least one collection imported

## Install

<Tabs>
  <TabItem label="Homebrew (recommended)">
    ```bash
    brew tap ryan-voitiskis/reklawdbox
    brew install reklawdbox
    ```
  </TabItem>
  <TabItem label="Build from source">
    Requires the [Rust toolchain](https://rustup.rs/) and Xcode Command Line Tools:

    ```bash
    xcode-select --install  # if not already installed
    git clone https://github.com/ryan-voitiskis/reklawdbox.git
    cd reklawdbox
    cargo build --release
    ```
  </TabItem>
</Tabs>

## Setup

```bash
reklawdbox setup
```

This installs audio analysis tools (Essentia) and configures both Claude Code and Claude Desktop so the agent can use reklawdbox.

<Aside type="note">
  Essentia needs Python 3.9+. If you don't have Python, grab it from [python.org](https://www.python.org/downloads/) or `brew install python`.
</Aside>

## Start a conversation

For Claude Code, start it from your Music directory:

```bash
cd ~/Music && claude
```

The setup command placed a config file in `~/Music` so the tools load automatically there. In other directories, the tools stay out of the way.

For Claude Desktop, the tools load globally — just open a new conversation.

## Verify it works

Paste this into your agent:

```text
Show me a summary of my Rekordbox library.
```

You should see your track count, playlist count, and genre distribution. If something's wrong, check [Troubleshooting](/troubleshooting/).

## Discogs authorization

Discogs provides labels, catalog numbers, and release metadata that power genre classification. It's preconfigured — no setup needed.

<Steps>

1. Ask the agent to look up any track on Discogs. On first use, you'll get an authorization URL — open it in your browser.

2. After authorizing, it works automatically from then on.

</Steps>

## Manual configuration

If `reklawdbox setup` didn't configure things correctly, or you want to add reklawdbox to other directories, you can set it up manually.

<Tabs>
  <TabItem label="Claude Code">
    Create a `.mcp.json` in the directory you want the tools available:

    ```json
    {
      "mcpServers": {
        "reklawdbox": {
          "command": "/opt/homebrew/bin/reklawdbox"
        }
      }
    }
    ```

    If you built from source, use the full path to your binary instead.
  </TabItem>
  <TabItem label="Claude Desktop">
    Add to your Claude Desktop config (`~/Library/Application Support/Claude/claude_desktop_config.json`):

    ```json
    {
      "mcpServers": {
        "reklawdbox": {
          "command": "/opt/homebrew/bin/reklawdbox"
        }
      }
    }
    ```
  </TabItem>
  <TabItem label="Codex">
    ```bash
    codex mcp add reklawdbox -- /opt/homebrew/bin/reklawdbox
    ```
  </TabItem>
</Tabs>

After changing config, reload your agent. In Claude Code, run `/mcp` or start a new conversation. In Claude Desktop, quit and reopen the app.
