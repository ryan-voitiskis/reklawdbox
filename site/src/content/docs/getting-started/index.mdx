## Prerequisites

- **macOS on Apple Silicon** (ARM64) — reklawdbox targets `aarch64-apple-darwin`
- **Rekordbox 7.x** installed with at least one collection imported

## Install

<Tabs>
  <TabItem label="Homebrew (recommended)">
    ```bash
    brew tap ryan-voitiskis/reklawdbox
    brew install reklawdbox
    ```

    The binary is installed to `/opt/homebrew/bin/reklawdbox`.
  </TabItem>
  <TabItem label="Build from source">
    Requires the [Rust toolchain](https://rustup.rs/) and Xcode Command Line Tools:

    ```bash
    xcode-select --install  # if not already installed
    git clone https://github.com/ryan-voitiskis/reklawdbox.git
    cd reklawdbox
    cargo build --release
    ```

    The binary is at `./target/release/reklawdbox`.
  </TabItem>
</Tabs>

## Essentia setup

Essentia provides danceability, energy, loudness, and spectral features used by genre classification, set building, and audio analysis. Install it before configuring your MCP host:

```bash
reklawdbox setup
```

This finds Python 3.9+, creates a managed venv, and installs Essentia via pip. It also auto-configures any detected MCP hosts (Claude Code, Claude Desktop). The venv is auto-detected at `~/.local/share/reklawdbox/essentia-venv` — no env vars needed.

<Aside type="note">
  Requires Python 3.9 or later. If you don't have Python installed, get it from [python.org](https://www.python.org/downloads/) or via `brew install python`.
</Aside>

## MCP host configuration

If `reklawdbox setup` already configured your MCP host, skip to [Verify](#verify). Otherwise, configure manually:

<Tabs>
  <TabItem label="Claude Code">
    Add for all projects:

    ```bash
    claude mcp add -s user reklawdbox -- /opt/homebrew/bin/reklawdbox
    ```

    Or register for a single project by adding `.mcp.json` to its root:

    ```json
    {
      "mcpServers": {
        "reklawdbox": {
          "type": "stdio",
          "command": "/opt/homebrew/bin/reklawdbox"
        }
      }
    }
    ```

    If you built from source, use `./target/release/reklawdbox` instead.
  </TabItem>
  <TabItem label="Claude Desktop">
    Add the following to your Claude Desktop config (`~/Library/Application Support/Claude/claude_desktop_config.json`):

    ```json
    {
      "mcpServers": {
        "reklawdbox": {
          "type": "stdio",
          "command": "/opt/homebrew/bin/reklawdbox"
        }
      }
    }
    ```

    If you built from source, use `./target/release/reklawdbox` instead.
  </TabItem>
  <TabItem label="Codex">
    ```bash
    codex mcp add reklawdbox -- /opt/homebrew/bin/reklawdbox
    ```
  </TabItem>
</Tabs>

<Aside type="tip">
  The Rekordbox database is auto-detected at `~/Library/Pioneer/rekordbox/master.db`. Set `REKORDBOX_DB_PATH` only for non-standard locations.
</Aside>

<Aside type="caution">
  After configuring your MCP host, reload it to pick up the changes. In Claude Code, run `/mcp` or start a new conversation. In Claude Desktop, quit and reopen the app.
</Aside>

## Verify

Start a new conversation and paste this:

```text
Show me a summary of my Rekordbox library.
```

It should return your track count, playlist count, and genre distribution. If it fails, check [Troubleshooting](/troubleshooting/).

## Discogs authorization

Discogs enrichment provides labels, catalog numbers, and release metadata used by genre classification and library cleanup. The broker is preconfigured — no env vars or setup needed.

<Steps>

1. Call `lookup_discogs` for any track. On first use, the broker returns an OAuth URL — open it in your browser.

2. After authorizing, subsequent calls work automatically.

</Steps>
