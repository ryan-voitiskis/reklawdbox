## Install

<Steps>

1. **Tap and install**

   ```bash
   brew tap ryan-voitiskis/reklawdbox && brew install reklawdbox
   ```

2. **Run setup** — installs audio analysis tools and configures Claude Code + Claude Desktop

   ```bash
   reklawdbox setup
   ```

3. **Start a conversation**

   ```bash
   cd ~/Music && claude
   ```

   Keep your host's normal permission checks enabled and approve only the
   reklawdbox tools and music paths the workflow needs. [Permission and safety details →](/concepts/safety/)

</Steps>

## Start here: Library Cleanup

You probably have metadata issues. Library Cleanup walks you through five sessions that fix naming conventions, enrich tracks from Discogs, Beatport, MusicBrainz, and Bandcamp, backfill missing labels and years, classify genres, and verify the results.

It's the foundation for everything else — enrichment data powers genre classification, and classified genres are used by set building and pool discovery.

## Safe by design

reklawdbox never writes to your Rekordbox database. Rekordbox metadata changes
are staged in memory and exported as XML for manual import. File-tag and
artwork tools are a separate, direct-write path, and the application also
creates local cache, backup, configuration, and export files.

- **Read-only database access** — your `master.db` is never modified
- **Staged Rekordbox metadata** — preview or discard metadata changes before export
- **Explicit file operations** — preview tag writes when available and review every target
- **Scoped host permissions** — keep normal prompts enabled and grant only what a workflow needs
