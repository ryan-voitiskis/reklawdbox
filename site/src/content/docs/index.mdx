## Safe by design

reklawdbox never writes to your Rekordbox database. Rekordbox metadata changes
are staged in memory and exported as XML for manual import. File-tag and
artwork tools are a separate, direct-write path, and the application also
creates local cache, backup, configuration, and export files.

- **Read-only database access** — your `master.db` is never modified
- **Staged Rekordbox metadata** — preview or discard metadata changes before export
- **Explicit file operations** — preview tag writes when available and review every target
- **Scoped host permissions** — keep normal prompts enabled and grant only what a workflow needs
