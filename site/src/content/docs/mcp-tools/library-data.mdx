## Library tools

---

### `read_library` <Badge text="no params" variant="note" />

{/* doc-contract:mcp tool=read_library schema=/ surface=none requiredness=global */}

Returns a library summary: track count, genre distribution, average BPM, key distribution, and rating breakdown.

---

### `search_tracks`

Search and filter tracks. All parameters are optional — combine any set of
[shared search filters](/mcp-tools/#shared-search-filters) with the local
options below.

{/* doc-contract:mcp tool=search_tracks schema=/ requiredness=global include=shared-search-filters */}

| Parameter | Type | Required | Description |
|-----------|------|:--------:|-------------|
| `playlist` | string | | Filter by playlist ID |
| `include_samples` | boolean | | Include Rekordbox factory samples (default: `false`) |
| `limit` | integer | | Max results (default: `50`, max: `200`) |
| `offset` | integer | | Skip first N results for pagination |

{/* /doc-contract:mcp */}

Factory sample tracks are excluded by default. Set `include_samples: true` to include them.

---

### `get_track`

Get full details for a single track by ID. Returns Rekordbox metadata only — use `resolve_track_data` for enrichment and audio analysis data.

{/* doc-contract:mcp tool=get_track schema=/ requiredness=global */}

| Parameter | Type | Required | Description |
|-----------|------|:--------:|-------------|
| `track_id` | string | **yes** | Track ID |

{/* /doc-contract:mcp */}

---

### `get_playlists` <Badge text="no params" variant="note" />

{/* doc-contract:mcp tool=get_playlists schema=/ surface=none requiredness=global */}

List all playlists with track counts. Returns the full playlist tree including folders and smart playlists.

---

### `get_playlist_tracks`

List tracks in a specific playlist, in playlist order.

{/* doc-contract:mcp tool=get_playlist_tracks schema=/ requiredness=global */}

| Parameter | Type | Required | Description |
|-----------|------|:--------:|-------------|
| `playlist_id` | string | **yes** | Playlist ID |
| `limit` | integer | | Max results (default: `200`) |

{/* /doc-contract:mcp */}

---

## Play history tools

---

### `get_sessions`

List recent DJ sessions from Rekordbox play history. Returns session ID, name, date, track count, and estimated wall-clock duration.

{/* doc-contract:mcp tool=get_sessions schema=/ requiredness=global */}

| Parameter | Type | Required | Description |
|-----------|------|:--------:|-------------|
| `limit` | integer | | Max sessions to return (default: `20`, max: `100`) |
| `after` | string | | Only sessions on or after this ISO date (e.g., `"2024-01-01"`) |

{/* /doc-contract:mcp */}

Duration is estimated from the timestamp span of tracks in the session plus the last track's length. Returns `null` for single-track sessions.

---

### `get_session_tracks`

Get the ordered track list for a specific DJ session. Each track includes a `played_at` timestamp showing when it was loaded during the session.

{/* doc-contract:mcp tool=get_session_tracks schema=/ requiredness=global */}

| Parameter | Type | Required | Description |
|-----------|------|:--------:|-------------|
| `session_id` | string | **yes** | Session ID from `get_sessions` |

{/* /doc-contract:mcp */}

---

### `get_play_stats`

Get per-track play statistics scoped by [shared search filters](/mcp-tools/#shared-search-filters). Shows play counts, last played dates, and which sessions each track appeared in.

{/* doc-contract:mcp tool=get_play_stats schema=/ requiredness=global include=shared-search-filters */}

| Parameter | Type | Required | Description |
|-----------|------|:--------:|-------------|
| `include_unplayed` | boolean | | Also return tracks matching filters that have never been played (default: `false`) |
| `limit` | integer | | Max results (default: `200`, max: `500`) |

{/* /doc-contract:mcp */}

Results are ordered by play count descending. When `include_unplayed` is `true`, unplayed tracks are appended after played tracks (ordered by title).

---

## Data resolution tools

Return locally-cached data without external API calls or analysis.

---

### `resolve_track_data`

Return Rekordbox metadata, cached Discogs enrichment, current Stratum and
optional current Essentia analysis, staged changes, and genre taxonomy mappings
for one track. It does not include cached Bandcamp or MusicBrainz payloads.

{/* doc-contract:mcp tool=resolve_track_data schema=/ requiredness=global */}

| Parameter | Type | Required | Description |
|-----------|------|:--------:|-------------|
| `track_id` | string | **yes** | Track ID |

{/* /doc-contract:mcp */}

---

### `resolve_tracks_data`

Batch version of `resolve_track_data`, with the same provider and freshness
boundaries. Accepts [shared search filters](/mcp-tools/#shared-search-filters)
to scope which tracks to resolve.

{/* doc-contract:mcp tool=resolve_tracks_data schema=/ requiredness=global include=shared-search-filters */}

| Parameter | Type | Required | Values | Description |
|-----------|------|:--------:|--------|-------------|
| `track_ids` | string[] | | | Specific track IDs (highest priority selector) |
| `playlist_id` | string | | | Resolve tracks in this playlist |
| `max_tracks` | integer | | | Max tracks to return (default: `50`) |
| `format` | string | | `["full", "classification"]` | `"full"` (default) or `"classification"` |

{/* /doc-contract:mcp */}

The `"classification"` format returns a compact payload (~400-500 bytes/track vs 2-4KB) with only genre classification fields: mapped Discogs genres/styles, audio features, and completeness flags.

<Aside type="tip">
  Use `format: "classification"` for large batches to keep context window usage low.
</Aside>

---

### `cache_coverage`

Report cache completeness for a track scope. Accepts [shared search filters](/mcp-tools/#shared-search-filters).

{/* doc-contract:mcp tool=cache_coverage schema=/ requiredness=global include=shared-search-filters */}

| Parameter | Type | Required | Values | Description |
|-----------|------|:--------:|--------|-------------|
| `track_ids` | string[] | | | Specific track IDs |
| `playlist_id` | string | | | Check tracks in this playlist |
| `max_tracks` | integer | | | Max tracks to check (default: unbounded) |

{/* /doc-contract:mcp */}

Returns exactly three coverage entries for the selected scope:

| Entry | What coverage means |
|-------|---------------------|
| `stratum_dsp` | Fresh built-in audio-analysis cache rows |
| `essentia` | Fresh optional Essentia cache rows, plus whether Essentia is installed |
| `discogs` | Exact album-aware `searched`, `has_result`, `matched_unmapped`, and `usable_genre` counts using the classifier's taxonomy mapping |

Bandcamp and MusicBrainz are targeted metadata paths and are not reported by
this tool.

The gap counts use the same scope: `no_audio_analysis` means no fresh Stratum
row, `no_enrichment` means Discogs has no usable mapped genre, and
`no_data_at_all` means neither audio analyzer nor Discogs has usable data.
`gaps.discogs` separates `not_searched`, `searched_no_match`, and
`matched_unmapped` work.

<Aside type="caution">
  For Discogs, `searched` excludes errors but includes a legitimate cached
  no-match. `has_result` counts exact or fuzzy payloads, while `usable_genre`
  requires at least one canonical mapped style. Error rows count as neither and
  can be retried. A row for another album does not satisfy classification
  readiness.
</Aside>
