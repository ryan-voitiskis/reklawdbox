## System overview

Single Rust binary (arm64), communicates with your MCP host over stdio. No runtime dependencies except an optional Python venv for Essentia.

- **MCP server** — tool calls over stdio, structured JSON responses
- **SQLCipher reader** — encrypted Rekordbox `master.db`, read-only, via rusqlite with bundled SQLCipher/OpenSSL
- **Internal SQLite** — WAL-mode cache for enrichment, audio analysis, and broker sessions
- **HTTP client** — reqwest + rustls for Discogs broker and Beatport
- **Audio analysis** — symphonia decode, stratum-dsp BPM/key detection (embedded)
- **Essentia** — optional Python subprocess for energy, danceability, spectral features

## Data flow

```
MCP Host (Claude Code / Claude Desktop / Codex)
  │
  │  stdio (JSON-RPC)
  ▼
reklawdbox (single Rust binary)
  ├── Rekordbox master.db ──── read-only, SQLCipher encrypted
  ├── Internal SQLite ──────── cache: enrichment, audio analysis, broker sessions
  ├── Discogs broker ───────── Cloudflare Workers + D1 (OAuth proxy)
  ├── Beatport ─────────────── HTML/JSON extraction (no API key needed)
  ├── stratum-dsp ──────────── embedded Rust audio analysis (BPM, key)
  ├── Essentia ─────────────── optional Python subprocess (energy, danceability)
  └── XML output ───────────── Rekordbox-compatible export files
```

## Rekordbox database

Rekordbox 6/7 encrypt `master.db` with SQLCipher 4 (AES-256-CBC). The key is universal across installations. reklawdbox bundles SQLCipher and handles decryption transparently.

### Key tables

| Table | Purpose |
|-------|---------|
| `DjmdContent` | Tracks — title, ArtistID, GenreID, BPM (int × 100), KeyID, Rating, `Commnt` (actual column name) |
| `djmdArtist` | Artist names (FK from DjmdContent) |
| `djmdAlbum` | Album names (FK from DjmdContent) |
| `djmdGenre` | Genre names (FK from DjmdContent) |
| `djmdKey` | Musical key names (FK from DjmdContent) |
| `djmdLabel` | Record label names |
| `djmdColor` | Color tag names (FK from DjmdContent) |
| `djmdPlaylist` | Playlists/folders (Attribute 0 = playlist, 1 = folder, 4 = smart) |
| `djmdSongPlaylist` | Track-to-playlist join table |

<Aside type="note">
  All primary keys are `VARCHAR(255)` strings, not integers.
</Aside>

## Discogs broker

TypeScript companion on Cloudflare Workers + D1. Acts as an OAuth proxy — reklawdbox never holds Discogs consumer secrets directly.

### Authentication flow

<Steps>

1. Call `lookup_discogs`. The broker checks for an active session.

2. If unauthenticated, the broker returns an OAuth URL. Open it in your browser.

3. After approval, the broker stores your OAuth token and returns a session token to reklawdbox.

4. Subsequent calls use the session token automatically. Deleting the internal database requires re-authorization.

</Steps>

<Aside type="tip">
  The broker is open-source and self-hostable. Set `REKLAWDBOX_DISCOGS_BROKER_URL` and `REKLAWDBOX_DISCOGS_BROKER_TOKEN` to point at your own deployment.
</Aside>

## Audio analysis pipeline

Two backends, cached per track in internal SQLite.

### stratum-dsp (always available)

Rust library embedded in the binary. Provides key detection (Camelot notation) and BPM detection. Key is preferred over Rekordbox; BPM is a fallback only (Rekordbox BPM is preferred because it's the value the DJ sees and can manually correct). No setup required.

### Essentia (optional)

Python subprocess adding advanced descriptors: danceability, rhythm regularity, spectral centroid (brightness), loudness (LUFS), onset rate, and dynamic complexity. Requires a Python venv — see [Getting Started](/getting-started/).

<Aside type="note">
  Without Essentia, energy falls back to a BPM proxy and brightness/rhythm axes score at a neutral 0.5.
</Aside>

Analysis runs once per track per backend. Use `skip_cached: false` to force re-analysis.

## CLI subcommands

The binary doubles as a standalone CLI. No MCP host required.

| Subcommand | Purpose |
|------------|---------|
| *(default)* | Start the MCP server (stdio) |
| `hydrate` | Batch enrichment + audio analysis |
| `analyze` | Batch audio analysis with filters |
| `read-tags` | Read native file tags (ID3, Vorbis, etc.) |
| `write-tags` | Write native file tags |
| `extract-art` | Extract embedded cover art |
| `embed-art` | Embed cover art into audio files |
| `setup` | Install Essentia (and optionally configure broker URL/token with `--broker`) |

See [CLI Commands](/cli/) for full usage.
